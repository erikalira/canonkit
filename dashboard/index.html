By model · effort
Window: retained history. Tokens are what the API counted, summed over every call of a dispatch: each call re-sends the whole context, so cache reads are counted again on every call. Σ total is processing volume, not new tokens and not cost. Output is a lower bound (the transcript often keeps only the count from the start of a call's stream); input and cache numbers are complete. Cache read % = cache read ÷ (input + cache read + cache write), summed over the dispatches with tokens. “with tokens” is how many dispatches the averages cover (a transcript that could not be read has none). Effort “inherited” means the dispatch passed none.
