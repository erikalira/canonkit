# OpenClaw Team Config

Configuração versionada da equipe de agentes OpenClaw.

Este repositório guarda prompts, skills, templates e scripts controlados manualmente.

## Regra principal

O runtime real do OpenClaw fica em:

~/.openclaw

Este repositório é a fonte da verdade para os arquivos que queremos preservar e reconstruir.

## Versionar

- AGENTS.md
- SKILL.md
- templates
- scripts
- documentação da equipe

## Não versionar

- tokens
- .env
- auth profiles
- logs
- caches
- sessões
- bancos SQLite
- arquivos temporários do runtime
