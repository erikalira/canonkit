# canonkit 2.1.0

## For users

**Action required: none.** Optional cleanup: delete the leftover
`~/.agents/<agent>.md` copies from 2.0, one file at a time, as described in
[Upgrading from 2.0](../install.md#upgrading-from-20-leftover-agentsmd).

- Core agents are installed to `~/.claude/agents` only (Claude Code). `~/.agents`
  receives skills only. Nothing verified reads `~/.agents/<agent>.md`, so
  `install` no longer writes it.
- Upgrading from 2.0: leftover `~/.agents/*.md` copies are harmless and nothing is
  deleted. `canonkit doctor` WARNs on them. 3.0 will remove the byte-identical
  ones; a modified copy is kept, and you can delete it by hand.
- No change in behavior of any gate.

## Internal

- The gates are now a pure `evaluate(evt, env)` core inside
  `hooks/canonkit-hook.js`; `main()` is the Claude Code adapter. Documented in
  [docs/hooks.md](../hooks.md) as an internal contract, not a public API.
- `install` copies an explicit per-adapter hook file list instead of a directory.
- New tests: purity, parity table and gate-map completeness for `evaluate()`.

## Next

- 2.2 (planned): adapters for other harnesses on top of `evaluate()`.
- 3.0: removes the byte-identical `~/.agents/<agent>.md` leftovers.
