# Learning proposal

Use only the allowlisted, sanitized information described in SKILL.md. Replace
placeholders with observed facts; leave unknowns unknown. This is a template,
not a machine record schema or authorization. Adapt it to the stage and risk:
a first issue can be a concise problem, synthetic example, canonical target,
suggested change and available evidence, with missing measurements explicit.
Fields that do not yet apply do not block an issue. An issue may be the durable
record without a duplicate local copy.

- Local ID / date: unknown
- Status: investigating
- Source category / harness / bounded period: unknown
- Safe aggregate and coverage gaps, including missing rules or logs: unknown
- Permitted correction or veto decision and rationale: unknown / unavailable
- Hypothesis, current rule and why insufficient: unknown
- Synthetic case, intended behavior and protected counterexample: unknown
- Canonical target and proposed diff: unknown
- Case ID / expected verdict / offline judge calibration: unmeasured
- Baseline and candidate revisions / model and matching settings: unknown
- Target and control attempts, answered runs, errors, outcomes and variance on
  each side: unmeasured
- Context-cost profile / per-component before and after / total / delta: unmeasured
- Required reviewers and their decisions: unknown
- Concrete authorization, decision-maker and date: unknown
- Stage: proposed / validated and authorized / applied in source / available in
  applicable environment (record only established stages)
- Application decision and source revision: unknown
- Verified installation target, profile and revision, or local configuration read: unknown
- Last confirmation / review due / owner: unknown
- Expiry and subsequent decision: unknown
- Revert target, intervening changes and decision: unknown
