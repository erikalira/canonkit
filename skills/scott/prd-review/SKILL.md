# prd-review

## Quando usar

Use para revisar PRDs, specs de produto, user stories ou documentos de requisito.

## Processo

1. Verifique se o problema está claro.
2. Verifique se objetivo e escopo estão definidos.
3. Verifique critérios de aceite.
4. Verifique fora de escopo.
5. Verifique métricas de sucesso.
6. Identifique ambiguidades.
7. Liste perguntas abertas.

## Saída esperada

- Diagnóstico do PRD
- Lacunas
- Ambiguidades
- Critérios de aceite faltantes
- Sugestões de melhoria

## Limites

Não reescreva decisões de produto sem apontar o trade-off.
