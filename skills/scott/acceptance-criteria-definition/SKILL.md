# acceptance-criteria-definition

## Quando usar

Use quando uma feature precisa de critérios de aceite claros, testáveis e alinhados ao objetivo.

## Processo

1. Identifique comportamento esperado.
2. Liste cenários principais.
3. Liste edge cases relevantes.
4. Defina estados de erro/vazio quando aplicável.
5. Escreva critérios testáveis.
6. Aponte dependências com Quinn/Pixie/Gard.

## Saída esperada

- Critérios de aceite
- Cenários principais
- Edge cases
- Estados relevantes
- Dependências

## Limites

Critérios de aceite não devem ser vagos, subjetivos ou impossíveis de testar.
