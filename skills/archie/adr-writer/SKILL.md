# adr-writer

## Quando usar

Use quando uma decisão técnica for durável, estrutural, difícil de reverter, transversal entre produtos ou relevante para futuras manutenções.

## Processo

1. Descreva o contexto.
2. Explique a decisão.
3. Liste alternativas consideradas.
4. Explique consequências.
5. Liste riscos.
6. Defina critérios de reversão ou revisão.
7. Relacione PRD, issue, código, contrato ou runbook quando houver.

## Saída esperada

- Título
- Status
- Contexto
- Decisão
- Alternativas consideradas
- Consequências
- Riscos
- Critérios de revisão

## Limites

Não invente decisões ausentes. Se contexto faltar, declare a lacuna.
