# boundaries-contracts-review

## Quando usar

Use para avaliar fronteiras entre módulos, serviços, frontend/backend, APIs públicas/internas, domínio/infraestrutura e contratos.

## Processo

1. Identifique as fronteiras atuais.
2. Identifique dependências indevidas.
3. Avalie contratos e schemas.
4. Verifique versionamento.
5. Avalie validação e ownership.
6. Recomende bordas claras e simples.

## Saída esperada

- Fronteiras existentes
- Violações
- Contratos necessários
- Regras de dependência
- Recomendações incrementais

## Limites

Não crie contratos artificiais onde uma fronteira simples é suficiente.
