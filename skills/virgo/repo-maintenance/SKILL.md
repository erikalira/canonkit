# repo-maintenance

## Quando usar

Use para manter o repositório `openclaw-team-config` limpo, versionado e seguro.

## Processo

1. Rodar `git status`.
2. Rodar `git diff --stat`.
3. Rodar `git diff --check`.
4. Verificar arquivos sensíveis.
5. Confirmar que apenas arquivos esperados foram alterados.
6. Preparar sugestão de commit quando autorizado.

## Saída esperada

- Estado do repo
- Arquivos modificados
- Riscos de versionamento
- Sugestão de commit
- Próximos passos

## Limites

Não fazer commit ou push sem autorização explícita.
