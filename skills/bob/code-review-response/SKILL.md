# code-review-response

## Quando usar

Use para responder comentarios de code review, ajustar PR, explicar decisao tecnica ou preparar follow-up a partir de feedback recebido.

## Processo

1. Leia cada comentario e identifique pedido, risco ou duvida.
2. Separe comentarios acionaveis de perguntas ou preferencias.
3. Verifique contexto e padroes locais antes de alterar.
4. Aplique ajustes pequenos e focados.
5. Explique quando nao aplicar uma sugestao e declare trade-off.
6. Rode validacoes relevantes.
7. Agrupe resposta por comentario ou tema.
8. Escale para outro agente quando o review pedir decisao fora de engenharia.

## Saida esperada

- Comentarios tratados
- Mudancas aplicadas
- Comentarios respondidos sem mudanca
- Justificativas
- Arquivos modificados
- Validacoes executadas
- Pendencias
- Dependencias

## Limites

Nao ignorar comentario sem resposta. Nao aceitar sugestao que amplie escopo, enfraqueca seguranca ou altere produto/arquitetura/UX/testes/deploy sem revisao responsavel.
