# adr-editor

## Quando usar

Use para revisar, clarear ou completar ADRs quando uma decisão durável, estrutural ou difícil de reverter precisar ficar compreensível e rastreável.

## Processo

1. Procure ADRs relacionados, PRD, spec, código, testes, contratos, issues e PRs.
2. Verifique se contexto, decisão, alternativas, consequências e critérios de revisão estão claros.
3. Preserve a decisão original; edite para clareza e rastreabilidade.
4. Registre lacunas quando faltarem contexto, alternativa considerada ou consequência.
5. Relacione documentos e artefatos conectados.
6. Peça revisão de Archie para decisões arquiteturais.
7. Peça revisão de Gard quando houver segurança, auth, dados sensíveis ou permissões.

## Saída esperada

- Título
- Status
- Contexto
- Decisão
- Alternativas consideradas
- Consequências
- Riscos
- Critérios de revisão
- Referências
- Lacunas

## Limites

Não aprove nem altere decisão arquitetural sozinho. Não invente alternativas, trade-offs ou justificativas que não estejam no contexto. Não use ADR para burocratizar mudança LOW reversível.
