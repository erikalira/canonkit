# knowledge-base-maintainer

## Quando usar

Use para manter documentação durável, links entre artefatos, índice de conhecimento, decisões relevantes e lacunas de documentação da equipe.

## Processo

1. Procure documentos existentes, PRDs, specs, ADRs, API docs, runbooks, issues, PRs e decisões anteriores.
2. Identifique documentos obsoletos, duplicados, ausentes ou desconectados.
3. Atualize links e referências sem alterar decisões de conteúdo fora do contexto.
4. Registre lacunas e proponha responsáveis quando a correção depender de outro agente.
5. Preserve rastreabilidade entre PRD, ADR, issue, PR, API docs e runbook.
6. Evite criar nova estrutura quando atualizar um documento existente resolver.
7. Escale para Virgo quando a organização de arquivos, templates ou sync do repo estiver em questão.

## Saída esperada

- Documentos encontrados
- Documentos atualizados ou sugeridos
- Links adicionados ou corrigidos
- Lacunas
- Conteúdo obsoleto
- Responsáveis ou revisores sugeridos
- Próximos passos

## Limites

Não reorganize a base de conhecimento em lote sem autorização. Não remova documentos sem revisão. Não registre conteúdo sensível, tokens, auth profiles, logs privados, caches ou dados pessoais desnecessários.
